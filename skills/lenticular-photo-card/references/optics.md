# 光栅选图的光学模型

`assets/template/renderer.js` 的 A/B 选择是光线追迹，不是按角度的交叉淡化。数值检查运行 `node scripts/check_optics.mjs`。

## 几何与参数（单位：一个透镜节距 p）

- 186 根竖直圆柱透镜，75 LPI 时 p = 0.3387 mm，卡宽 63 mm。透镜顶点在 z = 0，相邻圆弧在尖谷处相接（满宽圆弧）。
- 折射率 n = 1.57；顶点到印刷面厚度 t = 1.6p（0.542 mm）；半径 R = 0.64p（0.217 mm，矢高 0.24p）。
- R 取该厚度下法向入射 RMS 光斑最小的值（独立标量追迹复核）。它比近轴聚焦半径 t(n-1)/n = 0.58p 略大，用于平衡圆柱面球差。
- 印刷面是背面平面 z = -t，每个配准周期内各有半周期的 A/B；可选地在同一周期内重复2或3组A/B。干脆档的印刷边缘按 ±0.015 个组周期的方框模糊（单组时约 2400 dpi 一个墨点的一半），当前默认柔和端为 ±0.056 个组周期。参数定义见下节。
- 设计观看距离 D0 = 4 个卡宽（63 mm 卡约 252 mm）。
- 这是自洽的虚拟处方，不是对某个厂商片材的实测；DPL 等公开规格只给节距、厚度和标称视角，不能唯一确定曲面。

## 每个采样点的计算

1. 眼睛位置与 CSS 姿态共用同一角度（`TiltRenderer.pose`，±22° 横转、±14° 俯仰，透视 1500 px）。
2. 从眼睛到卡面该点的光线与所在透镜圆弧求交；若先越过尖谷，则改与相邻透镜求交。
3. 在交点按矢量 Snell 定律（空气→塑料）折射，直线传播到印刷面，得到落点。
4. 落点换算成印刷相位；像素足迹两端各追一条光线，在两落点之间对 A/B 方波做解析积分（不跨尖谷插值）。WebGL 每个子采样约 0.07p，Canvas2D 用同一函数每根透镜 8 段积分。
5. 落在第 j 个周期就取两张照片第 j 列（交错印刷的实际含义），因此水平分辨率受 186 列限制。

## 印刷节距配准

近轴推导：设计眼在正前方 D0 处，透镜中心 x 处的主光线入射角约 x/D0，在塑料中偏折为 x/(nD0)，落点约为 x(1 + t/(nD0))。要让所有透镜在设计位置同时落在 A|B 分界上，印刷节距应为

  p_print ≈ p (1 + t/(n D0))，即略大于透镜节距（符号已在本坐标系验证）。

实现时像印前“节距测试”一样数值求解：在设计眼位置，使最外侧透镜与中心透镜同时换面。得到 p_print = 1.001267p，比近轴值的超出量小 7.5%（最佳焦面球差使有效杠杆略小于 t/n）。该值在加载时固定，不随当前视线改变。

## 两个不同的换面参数

### 换面间隔：约28° / 15° / 10°

这项决定继续朝同一方向转动时，多久再次换回另一张照片，不是正面一次过渡的宽度。保持同一片透镜、折射追迹、固定配准节距和CSS姿态，只在每个原始印刷周期里重复 `m = 1、2、3` 组 A/B 条带。默认 `m = 1`，保留原版间隔。

落点仍先得到原始相位 `c`，计算A/B覆盖率时才映射为 `q = 0.5 + m × (c - 0.5)`。整数重复使相邻透镜的参考系仅相差整周期；锚定0.5让偶数档不翻转正面 A→B 的方向。照片空间列仍用原始 `c`，绝不能用 `q` 取列，否则照片本身会重复或跳切。`m = 1` 走原运算路径。

这是重复交错印刷的模拟，不是假装换了一个标称角度的商业镜片，也不是将输入角度倍增。三个选项为离散档位，标签是首个后续换面的近似值，不代表所有后续间隔都严格相等：在设计观距、最大柔和度下，独立CPU采样的首个后续50%交叉约为28.542° / 14.934° / 10.033°；三组时第二次约19.476°。实际观看距离、俯仰和采样精度会改变这些值。

印刷变密会更早进入离轴视区，也保留真实计算产生的串影。例如三组在+22°尚约有13%的另一面成分，但在+7.7°、+17.5°附近分别可达约99.8%的B、98.1%的A；这些为采样均值，非所有位置的保证。宿主应将角度端点标为“左转/右转”，不承诺端点总是A/B。若增加“查看A/B”按钮，应选择对应视区内的姿态，而不是机械地转到±22°。

### 过渡柔和度：干脆 → 柔和

这项调整每组A/B条带的边缘／等效采样斑半宽：`edge = 0.015 + 0.041 × flipRange`。`flipRange` 在0到1之间，当前默认1，干脆档为0。先将落点相位映射到组坐标，再在该坐标下加减edge。因此间隔缩短时，单次过渡的绝对角度也会缩短；这不是独立计时器或恒定秒数。

在原版单组、设计观距下，全卡B份额从10%到90%的总角度跨度约由2.6°增加到6.0°；不同观看距离、俯仰和采样精度会改变数值，不把它当作片材标称视角。调宽的代价是更长的串影区，不以端点强制夹紧掩盖它。

以相同速度转卡，更柔和的设置会更慢地完成一次换面。因此“换面速度”用这项柔和度表达，没有另加定时交叉淡化、相机迟滞或手势缓动。停止转卡，结果固定；逆向回到同一姿态，结果相同。两个参数适用于上传照片、Canvas2D降级及静态PNG导出，单图镭射不使用它们。恢复默认只重置这两个材质参数。

配准仍只用原版单组、0.015边缘初始化一次，之后固定；不随参数或当前视线重新配准，也不修改曲面、折射率、透镜节距、观看角或表面照明。原光学函数的省略参数仍指原处方，以兼容旧数值检查；应用/渲染状态的新默认明确传入最大柔和度。

## 原版参数下由模型得出的行为（不是预设）

- 正面换面：卡片平均 10–90% 约 2.6°，单根透镜约 2.4°（来自圆柱面像差和印刷边缘），其中每根透镜内部会先出现左右分裂的细条纹。
- 视区重复：约 ±28° 处换回另一张（顶点光线预测 27.9°）；离轴像差使这些边缘换面更宽、串影更多。滑杆 ±22° 落在第一视区内，所以端点是干净的 A/B，这是该处方的计算结果，不是端点强制。
- 眼距不等于 D0 时，换面从卡片一侧扫到另一侧。眼距 = 1500 px / 卡片 CSS 宽度：420 px 卡（3.57 卡宽）左右边缘相差约 1.7°，342 px 卡（4.39 卡宽）约 1.3° 且方向相反。即使在 D0，线性印刷节距对非线性落点仍留约 0.3° 的残差。
- 片材均匀：上下行对称，俯仰对称；没有噪声分区、随机遮罩、暗缝或时间相关项。同一姿态任何路径都得到同一结果。

## 局限

- 单点针孔眼；未模拟瞳孔大小、片材散射、厚度不均、透镜/印刷制造误差、卡片弯曲。
- 只追一次折射，不含表面反射造成的二次光路和全反射杂光；表面高光沿用原有照明近似。
- 原版单组宽于 ±22° 的视区在数值测试中验证，模板手势不转到那里。重复印刷档能在现有转动范围内看到多次换面，不扩大CSS旋转范围。
- 未与实拍卡逐角度标定；参考视频没有角速度信息。
