# 下一栈见 · 互动试玩

[在线试玩](https://lrondc.github.io/effects-playground/) · [液体玻璃](https://lrondc.github.io/effects-playground/glass/) · [Skill 原文和下载](https://lrondc.github.io/effects-playground/skill/)

两个独立的网页视觉实验：开合渐进对焦，以及液体玻璃。
可以拖动、慢放、选择自己的照片。照片只在访客浏览器中处理，不会上传。
无需登录、后端服务或模型 API；支持 WebGL 2 的浏览器即可运行。

Skill 包中附有可离线打开的完整模板、换图脚本和使用说明。

独立学习与视觉实验，非 Apple 官方项目，不会修改设备系统动画。
代码与图片来源见 [来源记录](skills/fold-focus-handoff/references/sources.md)
和 [第三方许可](skills/fold-focus-handoff/references/third-party.md)。

本仓库只包含公开静态成品；GitHub Pages 直接从 main 分支根目录发布。
