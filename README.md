# 下一栈见 · 互动试玩

[在线试玩](https://lrondc.github.io/effects-playground/) · [液体玻璃](https://lrondc.github.io/effects-playground/glass/) · [转转卡](https://lrondc.github.io/effects-playground/tilt-card/) · [Skill 原文和下载](https://lrondc.github.io/effects-playground/skill/)

三个独立的网页视觉实验：开合渐进对焦、液体玻璃，以及双图光栅 / 单图镭射的转转卡。
可以拖动、慢放、选择自己的照片。照片只在访客浏览器中处理，不会上传。
无需登录、后端服务或模型 API。开合与玻璃需要 WebGL 2；转转卡优先使用 WebGL 1，另有 Canvas 2D 回退。

转转卡支持可选相机跟随正脸位置，不追踪眼球、不录制、不上传画面。拒绝相机权限也能拖动试玩。
保存的 PNG 是静态角度图；可下载 [小红书小工具包](https://lrondc.github.io/effects-playground/tilt-card/tilt-card-xhs.zip)，仍须在平台模拟器和 Android / iOS 真机验证。

Skill 包中附有可离线打开的完整模板、换图脚本和使用说明。

独立学习与视觉实验，非 Apple 官方项目，不会修改设备系统动画。
代码与图片来源见 [来源记录](skills/fold-focus-handoff/references/sources.md)
和 [第三方许可](skills/fold-focus-handoff/references/third-party.md)。

本仓库只包含公开静态成品；GitHub Pages 直接从 main 分支根目录发布。
