# 最强效果光栅卡

[返回 Playground](../) · [下载小红书小工具 ZIP](tilt-card-xhs.zip) · [来源与第三方许可](THIRD_PARTY.md)

把两张照片放进同一张数字光栅卡，左右拖动查看另一面；也可以选择「单图镭射」，让彩光掠过 A 面照片。无需账号或模型 API。

## 怎么玩

1. 点击 A 面、B 面更换照片。支持 JPG、PNG、WebP，单张不超过 20 MB。
2. 需要时展开「裁切与位置」，设置缩放和左右、上下裁切。
3. 在「调效果」中选择材质、换面间隔、柔和度和一趟转动的时长。拖动卡片或点击「自动转动」查看效果，手机上方预览不会随编辑区滚走。
4. 点击「生成当前效果 GIF」。成品回到同一个预览位置，带上当前照片、裁切与效果设置，按所选 2/3/5 秒左→右→左循环；改动参数会回到编辑，需要重新生成。
5. 看过成品后点击「下载 GIF」。也可单独保存当前角度的静态 PNG。网页版会请求浏览器下载，但浏览器是否实际保存仍由设备决定。

「换面间隔」约28°/15°/10°三档，间隔越小，同向转动时越容易多次换面；「过渡柔和度」控制一次切换是干脆还是柔和，默认使用柔和端。度数是近似值，串影会随姿态改变。「恢复默认」回到原版间隔和最大柔和度，不清除照片、裁切或当前查看角度。键盘用户可聚焦卡片后用方向键，或展开「查看角度」调节滑块。

PNG 只保存当前角度，不携带换面交互。双图光栅是屏幕中的数字材质模拟，不是实体光栅打印，也不会生成照片中未拍到的三维视角。

GIF 为 360×480、20 fps 循环动画，使用相同光学计算；格式调色板会降低颜色精度。生成期间可取消，不会清除照片或参数。GIF 是固定轨迹动画，不是可交互网页。手机、桌面和导出共用固定的相对观看距离，不会因卡片缩小而改变换面边界。

双图光栅按视线与圆柱透镜的交点计算空气到塑料的折射，再读取背面的周期交错印刷条。印刷对位固定在一个设计观看距离，实际角度和观看距离决定换面先后与临界串影；不是按时间播放的透明度动画，也不人为安排上下两块遮罩。周期印刷允许更大角度下再次看到上一面，但不保证每一小段倾斜都会重复。

单图镭射使用固定的细小刻纹，让局部颜色随角度出现、熄灭，不在整张照片上铺常驻彩虹。两种材料都是数字近似，不是某款实物镜片的测量复刻。无 WebGL 的设备保留使用同一选图逻辑的二维降级预览，采样、反射与细纹精度会降低。

## 照片与保存

所选照片由页面在本机处理，不上传，也不主动持久化。关闭或刷新页面后，本次替换和调整不会保留，离开前请保存成品。相机入口暂时隐藏，不自动请求相机或麦克风权限。

下载行为及低性能设备表现会随浏览器和设备而异。网页测试不等于 Android / iOS 真机或小红书容器验证。
