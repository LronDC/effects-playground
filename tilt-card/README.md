# 转转卡

[返回 Playground](../) · [下载小红书小工具 ZIP](tilt-card-xhs.zip) · [来源与第三方许可](THIRD_PARTY.md)

把两张照片放进同一张数字光栅卡，左右拖动查看另一面；也可以选择「单图镭射」，让彩光掠过 A 面照片。无需账号或模型 API。

## 怎么玩

1. 点击 A 面、B 面更换照片。支持 JPG、PNG、WebP，单张不超过 20 MB。
2. 需要时展开「调整照片位置」，设置缩放和左右、上下裁切。
3. 拖动卡片、移动角度滑块，或聚焦卡片后使用方向键。Home / End 可直接查看 A / B 面。「演示一次」不会自动循环。
4. 点击「保存当前角度」生成静态 PNG。网页版会请求浏览器下载，并保留图片预览；未出现下载时，可长按预览，使用浏览器提供的图片操作。

PNG 只保存当前角度，不携带换面交互。双图光栅是屏幕中的数字材质模拟，不是实体光栅打印，也不会生成照片中未拍到的三维视角。

## 照片与相机

所选照片和相机画面由页面在本机处理，不上传，也不主动持久化。关闭或刷新页面后，本次替换和调整不会保留。

「试试探头看」是可选增强：点击后才请求相机权限并优先使用前置相机，只检测二维正脸中心位置，不追踪眼球、不做人脸身份识别、不录制、不请求麦克风。关闭相机、隐藏或离开页面时会停止相机；权限拒绝或检测失败仍可拖动。

相机需要浏览器允许的安全环境和用户授权。真实相机体验、下载行为及低性能设备表现会随浏览器和设备而异。网页测试不等于 Android / iOS 真机或小红书容器验证。
